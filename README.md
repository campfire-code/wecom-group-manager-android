用一台安卓手机登录企微 / 微信小号，让手机上的 App 按后台下发的任务自动执行：收发消息、建群、拉人踢人等。

## 下载

到 [Releases](https://github.com/campfire-code/wecom-group-manager-android/releases/latest) 下载 `wecom-group-manager-android_2.8.0-campfire.1_worktool-2.8.0.apk`，附 `SHA256SUMS.txt` 可核对。APK 来自上游官方发布，篝火没有修改。

## 使用前必读

- **需要自己准备一台安卓手机**，登录企微 / 微信小号，并在系统设置里开启本 App 的无障碍服务。
- **本仓库只有安卓端 App。** 它的工作方式是连接一个「后台」接收任务：App 默认连接上游厂商的云服务 `wss://api.worktool.ymdyes.cn`（见源码 `Constant.kt`），**聊天内容与任务会经过该云服务**。上游的后台 / 调度平台不在本仓库里，也没有看到开源的版本，能否自建以及怎么自建**未核实**；设置里可以改服务器地址，但需要自己有兼容的服务端。
- App 内置友盟（Umeng）统计 SDK（`app/build.gradle`、`MyApplication.kt`），会向友盟上报设备与使用统计；并会检查更新（`worktool.asrtts.cn`）。注重隐私的场景请自行评估。
- 上游说明：GitHub 上的是**开源历史版本**（最后一版 2.8.0，2023-10），上游的商业版仍在更新并适配新版企微 / 微信；这个历史版本**可能无法兼容当前的企微 / 微信新版本**（上游标注的兼容范围是旧版本），请先用小号确认。
- 接口说明见上游文档：https://worktool.apifox.cn/doc-850007
- **未实测**：篝火整理时没有安卓设备与企微账号，没有安装运行过，以上均依据上游源码与文档。
- 日志检查：源码里没有发现把 token、密钥、密码明文打印到日志的写法（按关键词检索，非逐行审计）；机器人编号（robotId）作为连接地址的一部分发往后台。
